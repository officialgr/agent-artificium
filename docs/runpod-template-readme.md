# Artificium

A general agent harness for long-term autonomous work, continual learning, and self-improvement.

This template starts a local llama.cpp model and opens Artificium's interactive setup in a browser terminal. Set your own `ARTIFICIUM_WEB_PASSWORD`, then open **HTTP port 7860** and sign in as **`artificium`**.

**[Source code, usage guide, and example prompts → GitHub](https://github.com/officialgr/agent-artificium)**
